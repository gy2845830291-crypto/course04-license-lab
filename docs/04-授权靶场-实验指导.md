# 第四课 · 授权靶场实验指导

目标：在已知源码的样本上，走完逆向全链路。答案在本文档末尾，请先自己动手。

## 阶段一 · 侦察

```bash
aapt dump badging "Android逆向课程第四课_授权靶场.apk" | grep -E "package|sdkVersion|native-code"
unzip -l "Android逆向课程第四课_授权靶场.apk" | head -40
```

确认 package 为 `edu.lab.rev.course04`、无 `lib/` 目录（无原生库、纯 Dalvik，smali 可直接读）。

## 阶段二 · 定位校验入口

```bash
apktool d "Android逆向课程第四课_授权靶场.apk" -o out
grep -rn "LAB4\|isValidKey\|LicenseCheck" out/smali/ | head -30
```

三条定位路线，任选：

1. 字符串锚点：`LAB4-` 这个前缀硬编码在校验函数里，全局搜即得。
2. 资源锚点：`lic_ok` / `lic_bad` 两个字符串 → 找 `MainActivity$onCreate$1` → 看它调用了谁。
3. 交叉引用：`jadx-gui` 打开后对 `isValidKey` 做 Find Usage，反向追到 Activity。

## 阶段三 · 还原算法

读 `LicenseCheck.smali`，把下面四个量抄出来：

1. 字符表（32 个字符的 const-string）；
2. 分组与长度规则（`LAB4-` 前缀、去横线后 15 字符）；
3. 位布局（payload 32 bit 的三个字段怎么切）；
4. 校验和算法（注意乘数是常量 `0x01000193`，这是 FNV 素数；初值 `0x811C9DC5`，这是 FNV offset basis）。

看到这两个常量，算法基本就定了。

## 阶段四 · 写本地校验器

用任意语言实现 `isValidKey`，要求：对随机串的判定结果必须与样本 100% 一致。
自检方式：随机生成 1000 个串，一半用你的生成器造、一半随机字符，两边判定逐条比对。

## 阶段五 · patch 点

两个层次，难度递增：

1. Java 层：`MainActivity` 里 `if-eqz` 改 `if-nez`（判定取反），或直接在 smali 里把 `isValidKey` 的返回处 `const/4 v0, 0x0` 改成 `0x1`。
2. 算法层：不 patch 判定，而是算出合法卡密直接输入——这是本课真正要练的。

patch 后必须重签名：`apksigner sign --ks lab.keystore ...`。

## 参考答案

- 字符表 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`
- 布局 `[31..16] userId | [15..4] expiryDays | [3..0] flags`，flags 必须含 bit2
- 校验和：FNV-1a 32（对 payload 大端 4 字节）xor 盐 `0x5A17C0DE`，取 `(h >>> 8) ^ h` 的低 8 位
- 参考实现见 `tools/keygen.py`
